# Security Policy

## Supported versions

Q8 Kernels is experimental software. Security fixes are handled on the
default branch when the affected code is still maintained.

## Reporting a vulnerability

Please do not open a public issue for an undisclosed vulnerability. Contact the
maintainer privately through the contact method associated with the GitHub
repository and include:

- a short description of the issue and affected component;
- the affected commit, tag, or installation method;
- reproducible steps or a minimal proof of concept;
- the impact you believe the issue has.

Do not include passwords, API keys, private model weights, or unrelated
personal data in a report.

We will acknowledge a report when practical, investigate it, and coordinate
public disclosure after a fix or mitigation is available.
